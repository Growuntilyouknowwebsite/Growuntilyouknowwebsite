# Grow Until You Know™ Website

Official website for Author Annette Cottingham and Grow Until You Know™ — books, learning resources, career guides, and inspiration for lifelong growth.

## Files

- `index.html` — homepage and page content
- `styles.css` — responsive site styling
- `script.js` — mobile navigation and automatic copyright year

## Deploying with Vercel

This is a static HTML/CSS/JavaScript site and can be deployed directly from a GitHub repository in Vercel.

## Editing

You can update text directly in `index.html`. Styles are in `styles.css`.
