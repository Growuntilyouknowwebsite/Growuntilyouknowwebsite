# Grow Until You Know™ Website

Official website for Author Annette Cottingham and Grow Until You Know™ — books, learning resources, career guides, healthy weekly inspiration, and encouragement for lifelong growth.

## Website sections

- Author and brand introduction
- Complete published-works overview
- Healthy beverage, meal, fruit, and exercise recommendations of the week
- Encouraging author read and quote of the week
- Amazon book shop and merchandise-coming-soon area
- Career Insight Guides
- Mission and contact information

## Files

- `index.html` — homepage structure and page content
- `styles.css` — responsive site styling
- `script.js` — weekly recommendations, mobile navigation, and automatic copyright year

## Updating the weekly recommendations

Open `script.js` and edit the text inside the `weeklyFeatures` section at the top. Keep the quotation marks and punctuation around each value intact.

## Deploying with Vercel

This is a static HTML/CSS/JavaScript site and can be deployed directly from this GitHub repository in Vercel. After it is connected, future updates to the `main` branch can deploy automatically.
